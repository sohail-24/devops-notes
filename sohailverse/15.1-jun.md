## 6. Academy Add Bug Fixed

Problem:

Frontend sent:

```json
{
  "skill":"Node.js",
  "category":"Language",
  "level":"Intermediate"
}
```

Worker expected:

```json
{
  "skill":"",
  "level":"",
  "description":""
}
```

Result:

```text
Add operation failed.
```

---

### Solution

Changed Worker API:

FROM:

```js
const { skill, level, description } = body;

INSERT INTO academy_posts
(skill, level, description)
```

TO:

```js
const { skill, category, level } = body;

INSERT INTO academy_posts
(skill, category, level)
```

After redeploy:

✅ Academy Add Working
