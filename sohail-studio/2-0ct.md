# 1. What is SOHAIL OS AI?

SOHAIL OS AI is a **new personal AI assistant for macOS**, built from scratch.

It is inspired by the idea of a personal Jarvis, but it is **not a Stonic AI clone**.

The long-term goal is:

```text
SOHAIL OS AI
│
├── Brain
│   ├── Ollama / Local LLMs
│   └── Model Router
│
├── Agent
│   ├── Intent Detection
│   ├── Planner
│   ├── Executor
│   └── Observer
│
├── Memory
│
├── Voice
│   ├── Speech → Text
│   └── Text → Speech
│
├── Mac Control
│   ├── Accessibility
│   ├── Apple Events / AppleScript
│   ├── Keyboard Events
│   ├── Mouse / Pointer Events
│   ├── Application Control
│   └── System APIs
│
├── Skills
│   ├── WhatsApp
│   ├── Safari
│   ├── Finder
│   ├── Terminal
│   ├── VS Code
│   ├── Git
│   ├── Docker
│   └── DevOps
│
└── Security
    ├── Permission Engine
    ├── Confirmation System
    ├── Trusted Apps
    └── Audit Log
```

Eventually the user wants commands such as:

> “Open WhatsApp and send a message to Wahab.”

Assistant:

> “What message?”

User:

> “Tell him I'll call him later.”

Assistant should eventually be able to operate the already-installed application without requiring a custom WhatsApp API.

**Important:** this functionality is future work. We are deliberately building the underlying Mac-control foundation first.

# 30. Security philosophy

Eventually SOHAIL OS AI will need different permission levels.

### Safe reads

Examples:

```text
What apps are running?
What app is active?
What is the system state?
```

Can be performed automatically.

### Low-risk actions

Examples:

```text
Open Safari
Focus VS Code
Open Finder
```

May eventually be allowed automatically depending on the security design.

### Higher-risk actions

Examples:

```text
Type something
Send WhatsApp message
Delete file
Run terminal command
Modify code
Push Git commit
```

Should require confirmation initially.

### Dangerous/destructive actions

Should always have explicit confirmation and strong safeguards.
